# 🚀 AI Agent Academy - Quick Start

## ⚡ **INSTANT PLAY** (30 seconds)

1. **Double-click** `index.html` 
2. **OR** drag `index.html` into any browser
3. **Start playing immediately!**

## 🎮 **FIRST GAME SESSION** (5 minutes)

### Step 1: Build Your Agent
- Click "🔧 Agent Builder"  
- Drag "📥 Input Layer" to canvas
- Drag "🧠 Dense Layer" to canvas  
- Drag "📤 Output Layer" to canvas
- Click "🔨 Compile Agent"

### Step 2: Train Your Agent
- Click "📊 Training Arena"
- Select dataset (any option)
- Click "🎯 Start Training"
- Watch progress bars fill up!

### Step 3: Test Your Skills  
- Click "🎯 Challenges"
- Try "📱 App Review Classifier" 
- See if your agent passes!

### Step 4: View Your Progress
- Click "🏆 Agent Gallery"
- See your completed agents

## 🌐 **DEPLOY ONLINE** (2 minutes)

### Netlify (Easiest)
1. Go to https://app.netlify.com/drop
2. Drag entire `ai-agent-academy` folder
3. Share the live URL!

### Local Server
```bash
# In the ai-agent-academy folder:
python -m http.server 8000
# Then visit: http://localhost:8000
```
