# 🎮 AI Agent Academy - Demo Script

## 🚀 **5-Minute Demo Flow**

### **1. Welcome & Overview (30 seconds)**
- Open `index.html` in browser
- Show main interface: "🤖 AI Agent Academy" 
- Point out game stats: Credits, Agents Built, Level
- Highlight the educational approach: "Learn AI by building agents"

### **2. Agent Builder Demo (2 minutes)**
- Click "🔧 Agent Builder"
- **Drag components:** Show drag-and-drop from left panel
  - Start with "📥 Input Layer" 
  - Add "🧠 Dense Layer"
  - Add "🎯 Dropout" (explain: prevents overfitting)
  - Finish with "📤 Output Layer"
- **Compile Agent:** Click "🔨 Compile Agent"
- Show agent summary with parameters and estimated cost

### **3. Training Arena Demo (2 minutes)**  
- Click "📊 Training Arena"
- **Select Dataset:** Choose "🖼️ Image Classification"
- **Adjust Hyperparameters:** 
  - Move Learning Rate slider (explain impact)
  - Adjust Batch Size (show cost changes)
- **Start Training:** Click "🎯 Start Training"
- Watch live progress bars and console output
- **Results:** Show final accuracy and credit rewards

### **4. Challenges Demo (30 seconds)**
- Click "🎯 Challenges" 
- Show progressive difficulty: Easy → Hard
- Explain real-world applications:
  - "📱 App Review Classifier" (sentiment analysis)
  - "🖼️ Image Recognition" (computer vision)
  - "🎵 Music Recommendation" (collaborative filtering)
- Attempt a challenge with trained agent

### **5. Wrap-up & Impact (1 minute)**
- Click "🏆 Agent Gallery" - show created agents
- Highlight learning progression and achievements
- **Educational Value:** 
  - "Students learn neural networks by building them"
  - "Real datasets, real challenges, real skills"
  - "Gamification makes AI concepts addictive"
- **Deployment:** "Ready for schools, bootcamps, corporate training"
